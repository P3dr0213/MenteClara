# Projetos nativos anteriores

As pastas android e ios foram preservadas aqui como referência da versão React Native CLI.
Não são usadas pelo Expo nem enviadas ao EAS Build. Para builds nativos novos,
use `npx expo prebuild` na raiz, que gera projetos compatíveis com o SDK atual.
O aplicativo Expo usa SecureStore: faça login novamente ao abrir a nova versão.
